# RNR Rent Car

Учебный full-stack сервис проката в Ташкенте: React 18 + Vite + JavaScript, Express, Prisma 5 и настоящий PostgreSQL. Цены, аккаунты, отзывы, платежи и контакты демонстрационные. Фиксированный курс: **1 USD = 11 900 UZS**.

## Запуск

Требуется Node.js 20+ и npm. Все команды ниже запускаются из корня репозитория.

```sh
npm run setup
cp server/.env.example server/.env
```

В `server/.env` задайте уникальный `JWT_SECRET`, пароль PostgreSQL в `DATABASE_URL`, `DEMO_ADMIN_PASSWORD`, `DEMO_MANAGER_PASSWORD`, `DEMO_CUSTOMER_PASSWORD` (минимум 8 символов). Не публикуйте этот файл. В текущем локальном окружении конфигурация уже создана, пароли случайные и находятся только в `server/.env`. Предыдущая конфигурация сохранена в игнорируемом `server/.env.original`.

В первом терминале запустите локальную базу:

```sh
npm run db:local
```

Это настоящий PostgreSQL из пакета embedded-postgres, с данными в `.local/postgres`, доступен только на 127.0.0.1. По умолчанию порт 55432. Для внешнего PostgreSQL укажите его URL и пропустите `db:local`. Никогда не используйте локальную демонстрационную конфигурацию в production.

Во втором терминале:

```sh
npm run db:migrate
npm run db:seed
npm run dev
```

Сайт: http://localhost:5173. API: http://localhost:4000/api. `/api/health` проверяет подключение базы и возвращает 503 при недоступности.

Seed создаёт 15 моделей и данные без дубликатов, повторный запуск сохраняет изменения администратора. Учебные аккаунты:

- `admin@rnrrentcar.uz` — пароль из `DEMO_ADMIN_PASSWORD`;
- `manager@rnrrentcar.uz` — пароль из `DEMO_MANAGER_PASSWORD`;
- `aziza@example.test`, `timur@example.test`, `malika@example.test` — пароль из `DEMO_CUSTOMER_PASSWORD`.

Сброс пароля существующего пользователя:

```sh
cd server
RESET_PASSWORD='новый-временный-пароль' node prisma/reset-password.js admin@rnrrentcar.uz
```

## Основные сценарии

Каталог загружается из базы, фильтры сохраняются в URL, страницы моделей открывают галерею, избранное и бронирование. Стоимость рассчитывается сервером из актуальных цен автомобиля и услуг. Каждые начатые 24 часа — сутки; услуги начисляются за сутки. Времена бронирований интерпретируются в UTC+5. Залог учитывается отдельно.

Создание бронирования и планирование обслуживания блокируют строку автомобиля в транзакции PostgreSQL. Пересечение проверяется для полуоткрытых интервалов: возврат в момент следующей выдачи допускается. Завершённые и отменённые аренды не блокируют новые даты. Обслуживание блокирует соответствующий период. Клиент видит только свои заявки и может отменить новую/подтверждённую до её начала.

Менеджер подтверждает заявку, проверяет документы, сохраняет пробег, топливо, фотографии и повреждения, выдаёт автомобиль. При возврате система сохраняет осмотр, начисления и переводит автомобиль в подготовку. Важные действия сохраняются в AuditLog. Пароли и секреты не возвращаются клиенту.

Админка: операции, автопарк и медиа, бронирования с поиском и историей, календарь, выдачи, возвраты, клиенты, платежи, залоги, повреждения, обслуживание, услуги, модерация отзывов, обращения, сотрудники и настройки. Admin управляет настройками и ролями; manager работает с операциями и автомобилями. Права проверяются сервером.

Форма контактов сохраняет обращение; сообщение об успехе показывается только после ответа API. Телефон, email, часы и адрес редактируются администратором. Неподтверждённая карта и фиктивные соцсети удалены.

## Медиа

Настоящие файлы Hero находятся в `client/public/media/hero/`, MP4 имеет длительность около 34 секунд, 1280×720. Видео воспроизводится автоматически без звука, циклически; есть кнопка звука и постер. Исходные видео были в проекте до доработки; их авторство и право коммерческого использования не подтверждены.

Фотографии импортируются из Wikimedia Commons по заранее выбранному списку, только с CC BY, CC BY-SA, CC0 или public domain. Авторы, лицензии, исходные URL, время импорта и ошибки записаны в `client/public/media/manifest.json`. Атрибуция видна в галерее. Фотографии показывают модель; год и комплектация конкретного прокатного экземпляра не заявляются. Для Chazor используются фотографии модели Chazor/Destroyer 05, без подтверждения комплектации Champion. Неподтверждённые характеристики в каталоге не заполнены.

Импорт (Python 3 + Pillow):

```sh
python3 -m venv .local/media-tools
.local/media-tools/bin/pip install -r scripts/requirements.txt
.local/media-tools/bin/python3 scripts/import-media.py
npm run db:seed
node scripts/check-media.js
```

Импорт пропускает существующие файлы, не создаёт дубликаты, сохраняет ошибки и продолжает другие модели. При ограничениях источника повторите позже. Фотографии оптимизируются в WebP до 1280px. Нельзя заменять недоступную фотографию другой моделью.

Реального набора 360° кадров пока нет. Viewer честно сообщает о недоступности. Администратор может загрузить реальные последовательные кадры через раздел «Медиа». Компонент поддерживает drag/touch, кадры, масштабирование и fullscreen; один кадр не выдаётся за 360°.

## Проверки

```sh
npm run build
npm test
npm run test:smoke
npm run test:regression
npm run test:browser
```

API smoke требует запущенного backend и seed. Он проверяет конкурирующие заявки, расчёт, авторизацию и роли, чужие заявки, выдачу/возврат, избранное, контакты и аудит. Созданные проверкой записи очищаются. Браузерные проверки включают реальное оформление и отмену бронирования. Browser smoke требует Vite и Chrome; на других платформах задайте `CHROME_PATH`. Скриншоты сохраняются в `.local/screenshots`.

## GitHub

Workflow `.github/workflows/ci.yml` запускает сборку клиента и unit-тесты сервера при push и pull request. Для полной локальной проверки API дополнительно нужны PostgreSQL, миграции и seed — эти интеграционные проверки не запускаются в CI.

Чтобы опубликовать код в новом GitHub-репозитории:

```sh
git init -b main
git add .
git commit -m "Prepare RNR Rent Car for GitHub"
git remote add origin https://github.com/<OWNER>/<REPOSITORY>.git
git push -u origin main
```

GitHub Pages не подходит для полного приложения: там нельзя запустить Express API и PostgreSQL. Для публичного production-запуска клиент, API и база должны быть развернуты отдельно; перед публикацией публичного репозитория подтвердите право распространять исходное Hero-видео (сейчас оно не подтверждено). Локальные `.env`-файлы, база и загруженные пользователями файлы исключены из Git.

## Ограничения

Это локальный учебный проект. Банковский шлюз, email/SMS-рассылки, коммерческие контакты и действительные договоры не подключены. Production-развёртывание требует HTTPS, резервного копирования, отдельного хранилища медиа и подтверждённых прав на Hero. Удаление/архивация изображений не удаляет исходный файл из хранилища. Реальные 360° кадры отсутствуют. Регистрация не загружает паспортные документы: менеджер подтверждает их ручную проверку при выдаче.

Альтернативная база через Docker Compose: задайте `POSTGRES_PASSWORD` в окружении, выполните `docker compose up -d` и используйте такой же пароль в `DATABASE_URL`. Не запускайте эту базу одновременно с `db:local` на том же порту. Docker-вариант подготовлен, но в текущем окружении не запускался.


## Последующая доработка

- Сессии сохраняются в PostgreSQL (`AuthSession`): выход отзывает текущую сессию, смена пароля завершает все сессии пользователя. Смена пароля доступна в профиле; сброс через CLI также отзывает сессии. После обновления с прежней версии потребуется войти заново.
- Каталог фильтрует, сортирует и разбивает данные на страницы непосредственно в базе. Год и привод работают и без дат. Календарные даты, время UTC+5, пагинация и цены валидируются; несуществующие даты вроде 30 февраля отклоняются.
- Менеджер редактирует период и места заявки или продлевает активную аренду. Согласованная суточная ставка сохраняется; стоимость и доступность пересчитываются в транзакции. Просроченная активная аренда блокирует новые заявки до возврата автомобиля.
- Архив имеет отдельный список и восстановление. Автомобиль с открытой арендой нельзя архивировать даже при просроченной дате возврата. После восстановления машина проходит подготовку.
- Можно изменить двигатель, привод, цвет, уровень топлива, комплектацию и главное фото; добавить или удалить 360° кадры. Главное фото первым открывается на странице модели. Галерея сбрасывается при смене автомобиля, поддерживает клавиатуру и удерживает фокус внутри открытого окна.
- Загрузки до 8 МБ декодируются через Sharp: принимаются корректные JPEG/PNG/WebP до 32 МП, изображения автоматически уменьшаются до 1920×1440 и сохраняются в WebP без исходных метаданных. Повреждённый файл с поддельным заголовком отклоняется. API проверяет существование файла до его привязки к автомобилю.
- Клиент получает уведомления об изменении заявки, выдаче и возврате. Внутренние заметки менеджера не возвращаются через клиентские API. В деталях заявки видны период, услуги, стоимость и результаты выдачи/возврата; есть печатная учебная карточка, которая не является подписанным договором.
- Стоимость ремонта редактируется в разделе повреждений. Администратор включает и отключает услуги; менеджер видит их без управления ценами. Раздел сотрудников отделён от списка всех пользователей и ролей.
